# file-magic-identifier
Identifies file type based on magic numbers, providing a stronger check than file extensions alone. Uses the `python-magic` library. - Focused on File operations and analysis

## Install
`git clone https://github.com/ShadowStrikeHQ/file-magic-identifier`

## Usage
`python3 main.py <file_path> [-v]`

## Parameters
- `file_path`: Path to the file to identify (required, positional)
- `-h`: Show help message and exit
- `-v`: Enable verbose logging.
